瀏覽器 --> PUT --> Railway: /api/projects/{id} --> 比對 features done 狀態 --> notifier._send() --> HTTPS --> Telegram API --> 手機收到推播

Mac Stock Server --> Tailscale --> Win11 XQ Bridge :8000 --> COM/RTD --> XQLite --> 即時報價 JSON

Benjamin iframe --> cloudflared --> Mac :8001 POST /jobs --> yt-dlp 下載 --> Whisper 轉錄 --> Gemini 分析 --> Google Slides API

你的系統用到的架構觀念

1. 前後端分離 (Frontend-Backend Separation)

前端（dashboard.html）和後端（main.py）各自獨立。前端透過 fetch 呼叫 API 取資料，後端只回 JSON。兩邊可以各自修改，互不影響。

你的實作：dashboard.html 用 fetch("/api/projects") 取資料，main.py 只負責 JSON CRUD

2. 微服務 (Microservices)

系統拆成多個獨立服務，各自部署、各自重啟不影響彼此。每個服務只做一件事。

你的實作：balian-quant（量化分析）、gent（提醒機器人）、video2slides（影片轉簡報）是三個獨立服務，掛一個不影響其他

3. Bridge / Adapter 模式

當兩個系統語言或環境不同時，中間放一個「翻譯層」。把專有格式轉成通用格式（REST JSON）。

你的實作：XQ Bridge 把 Windows COM/RTD 協定轉成 REST API，讓 Mac 和 Railway 都能用 HTTP 取報價

4. Webhook vs Polling

Polling：定時去問「好了沒？」（health check 每 30 秒 ping）。
Webhook：事情發生時主動通知你（Telegram bot 用 webhook 接收訊息）。Webhook 更即時、更省資源。

你的實作：gent 用 webhook 模式接收 Telegram 訊息；Benjamin 用 polling 做 health check

5. 事件驅動通知 (Event-Driven Notification)

不是定時檢查，而是「狀態改變時」才觸發動作。省運算、即時性高。

你剛加的功能：update_project 時比對 done 新舊值，變成 true 才發 Telegram，不是每分鐘去掃 projects.json

6. Tunnel / 內網穿透

本機服務（沒有公開 IP）透過隧道對外提供服務。常見方案：Tailscale（VPN 互連）、cloudflared（HTTP tunnel）、ngrok。

你的實作：Mac <-> Win11 用 Tailscale 互連；video2slides 用 cloudflared 給 Benjamin iframe 嵌入

7. 單一資料來源 (Single Source of Truth)

同一份資料只存一個地方，其他地方都來這裡讀。避免資料不一致。

你的實作：專案資料統一存 projects.json，dashboard 和 API 都讀同一份；待辦統一存 PostgreSQL

8. Pipeline 模式

把複雜任務拆成一連串步驟，每步輸出是下步輸入。好處：每步可獨立測試、可加快取跳過已完成的步驟。

你的實作：video2slides 的 下載 -> 抽音訊 -> 轉錄 -> 場景偵測 -> AI 分析 -> 生成 Slides -> 匯出

你做過的架構決策與取捨

決策 你選的 另一個選項 取捨原因
即時報價來源 XQ Bridge + Tailscale 純雲端券商 API XQ 有自選組合和 RTD 即時流，券商 API 有延遲限制
歷史K棒 FinMind 免費 API XQ COM 或爬蟲 XQ RTD 只有即時沒有歷史；爬蟲不穩定
專案資料儲存 projects.json 檔案 資料庫 快速啟動、簡單，但重新部署會覆蓋資料（未來可能要改 DB）
AI 內容分析 Gemini 免費層 Claude API（付費） Max 訂閱不含 API 額度，Gemini 完全免費
Health Check 瀏覽器端 fetch 後端 requests.get() Railway 雲端打不到 Tailscale 私有 IP，只有瀏覽器（在你的區網）能 ping
video2slides 對外 cloudflared quick tunnel Railway 部署 / named tunnel quick tunnel 免設定但重啟會變 URL（暫時方案）
Mac <-> Win11 連線 Tailscale VPN ngrok / port forwarding 固定 IP、不怕重啟、雙向互通、免費
